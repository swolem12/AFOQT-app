What to Verify

  • Registry aggregation: new part3 files for aviation, block counting, instrument comprehension, physical science, table reading, and RC passages 21–25 appear in filters.
  • Rendering: questions show stems, choices, answer highlight (when toggled), explanations.
  • Search: keyword search surfaces newly generated items.

Hints

  • Toggle “Show answers/explanations” in the admin page to reveal solutions.
  • Use subject/subtopic/difficulty filters to jump to the new part3 files.
  • Table Reading items embed tableSpec; confirm X/Y labels and lookup values render.
  • Reading Comprehension passages 21–25 each include 5 questions; search “redundancy” to spot-check.
