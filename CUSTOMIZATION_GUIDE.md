# Quick Reference Guide - New Features

## 🎨 Customization Options

### Where to Find Settings
**Main Menu → Settings → Appearance Section**

---

## 🎬 Intro Animation
**What it does:** Plays an animated logo and loading sequence when you first open the app

**Options:**
- ✅ Enabled - Show intro animation on launch
- ❌ Disabled - Skip directly to boot screen

**How to skip:** Click "TAP TO SKIP" or press any key

## 🎯 Pro Tips

### Mix and Match
Try different combinations:
- **Cinematic Experience:** Video theme + Cinematic UI + Layered panels
- **Clean Focus:** Minimal theme + Minimal UI + Grid panels
- **RPG Adventure:** Panel theme + RPG UI + Bracket panels
- **Classic Mode:** Default theme + Classic UI + Default panels

### Total Combinations
**7 themes × 4 UI styles × 6 panel styles = 168 unique looks!**

### Quick Reset
If you want to go back to the original look:
- Theme: Default
- UI Style: Classic
- Panel Style: Default
- Intro Animation: Enabled
